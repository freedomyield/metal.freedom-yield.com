未事前構築

Subnet 検証には、別途 metalgo プロセスと専用 CPU/RAM/disk が通常必要です。現状の単一 VPS 構成は primary network 専用にサイジングされており、subnet 用に遊休容量を予約していません。subnet 検証用ホストの新規プロビジョニングは合理的な事前通知があれば対応可能ですが、事前構築はしていません。小規模 validator として遊休在庫を抱えない、という意図的な honest 開示です。

鍵の保管

専用 validator ホスト上の ed25519 staking key は自己保管。バックアップ方針に従いホスト外に暗号化保管。第三者保管なし、共有鍵材料なし。Off-chain 署名済 manifest 用の operator identity key は別の専用鍵で、validator ホスト上には一切置かない設計。

Subnet pilot 受入適性

要請に応じ bilateral

Subnet pilot 招聘があれば、運用者は合理的な事前通知のもとで subnet 検証専用ホストを立ち上げ可能です。pilot の具体的な形(容量サイジング・応答時間 SLA・subnet 固有のコンプライアンス・カストディフレーム・コミュニケーション頻度)は必然的に bilateral 協議です。本ページではそれらを事前確約しません — 受入意思と構造的実現可能性のみ確認します。

本ページが「ではない」もの

本ページは compliance attestation、規制開示、特定 subnet への入札、特定の評価フレームワークを満たしたという表明、のいずれでもありません。現在の運用が「何を持っており、何を持たず、要請があれば何を準備できるか」を 1 ページで率直に述べたものです。検証可能な実体は、相互リンクしている各 artifact(selection evidence・リスク開示・コミットメント・管轄・事業継続性)にあります。
