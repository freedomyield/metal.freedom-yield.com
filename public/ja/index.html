このバリデータについて

Freedom Yield は、過大な運用能力を主張するのではなく、公開された運用証跡を重視する small-but-transparent な Metal Blockchain validator です。

日本拠点で Metallicus エコシステムに参加しています。

運用方針

Snowman consensus ではサーバスペックは 合否判定型です — 公式最小を満たせば それ以上のマシンを動かしても報酬は増えません。当方は公式最小ラインで運用し、 ハードに使うはずだったコストを uptime / 監視 / インシデント対応に振り向けます:

  • 異常検知の push 通知体制(container / disk / memory / peer / validator 脱落)
  • 期間更新締切のリマインダー(T−7 日 / 前日 / 当日 / 10 分前 — urgent は最後の 1 通のみ)
  • 運用サマリを 1 日複数回プッシュ
  • 四半期ごとの災害復旧ドリル(暗号化バックアップ + NodeID 再現性検証)

自己 stake は意図的に小さく抑えています(現時点でネットワーク内では小規模側)。利回りを追わず、 受入枠は各サイクルで漸進的に拡大していく方針です。現値はステータスカードに表示中、 /api/validator.json から live で取得しています。

peer-set の full snapshot、validator 集中度の履歴、fee market のパーセンタイル、incident timeline、 renewal calendar 本体 ── 運用の生データをオープンに公開しています。一覧は /data/ にあります。

インフラ

  • Metallicus 公式最小推奨を余裕で上回る production-grade VPS
  • NVMe-class ローカルストレージ(ネットワークファイルシステムは validator hot path で使用しない)
  • Port 9651/TCP のみ inbound 公開、他は遮断
  • 本サイトとは別ホストで運用(障害分離)

補足: バリデータと end user との距離は委任者の体験に影響しません。 region 選定の理由は「ピア群への RTT」と「運用者 SSH の応答性」であって、 委任者の操作が遅くなることはありません。

選ばれる理由

  • 委任手数料 3%

    プロトコル下限 2% の 1 つ上。予測可能な手数料、突発的な引き上げはありません。

  • 能動的な監視体制

    24/7 uptime 監視、コンテナ / disk / peer 異常の自動 push 通知、期間更新の前倒し対応。

  • 長期参加方針

    短期の規模拡大ではなく、長期サイクルにわたる継続性を重視します。

  • スラッシングなし

    Metal Blockchain にはスラッシングがありません。ダウンタイム時のペナルティは報酬ゼロのみ。委任元本がプロトコルで毀損されることはありません。

  • 透明な実績

    本ページの全数値はノードから live 取得。状態 JSON は /api/validator.json で公開しています。

みんなのおかげ — 横のつながり

Metal Blockchain は世界中のバリデータが協調して支える分散ネットワークです。 現時点で ~200 の独立オペレータがブロックごとに投票しています。 当方のノードもその 1 つ、それ以上でも以下でもありません。 Snowman consensus は多様性で強くなる設計で、他バリデータがいなければ私たちも機能しません。

計算式と支払いルール

報酬 = 元本 × APY × (lock 日数 / 365) × uptime factor × (1 − 3% 手数料)。uptime 80% 未満ではネットワークから報酬が一切発生しないため、80% の値が「現実的な最悪値」です。

今後の展望

ロードマップ

validator は終わりのあるプロジェクトではなく、長期間の規律です。約束していること、今後の判断軸を明示します。

  1. 2026-05 → 2027-05 進行中

    Phase 1 — 積み増し

    12 か月 × 月次 cycle で運用。各 cycle で tx 投入 → ~30 日間稼働 → 再登録。外部資金の段階的 deploy で self-stake を ~3,000 METAL ずつ積み増し、cycle ごとに監査トレース(uptime ledger / incidents / cadence)を公開。委任獲得は積極追求せず、来れば lucky。1 年後に確実に残るもの: 12 cycle 完走実績と公開された監査トレース。

  2. 2027-05 判断点

    Phase 2 review

    12 cycle 完走 + 12 か月の監査トレース蓄積。この時点で再判断: cycle 期間を延ばすか? 委任獲得を本格化するか? 判断は今 roadmap に書いた線ではなく、1 年間蓄積した事実ベースで行います。

  3. 期限なし Long-term

    Beyond Phase 2

    Metal Blockchain ecosystem の進化に合わせて継続的に貢献。validator 運営に終わりはなく、約束できるのは operational quality の継続だけ。

よくある質問

01運用 バリデータがオフラインになったら?

ネットワーク評価値 uptime が 80% を下回ると、その期間の報酬(バリデータ + 委任者ともに)はゼロになります。ただし 元本が削られる(スラッシング)ことはありません。委任した METAL はバリデータ挙動に関わらず期間満了時に必ず戻ります。

02経済 ロック期間はどのくらいですか?

14 日〜1 年の範囲で自由に選択できます。期間が長いほど APY がわずかに高くなります。ただし委任期間は本バリデータの残り期間を超えることはできません。

03経済 報酬の支払いタイミングは?

選択した lock 期間の終了時に、元本と報酬が一括で P-Chain の指定アドレスに解放されます。途中での部分支払いはありません。

04経済 途中で委任を取り消せますか?

できません。Metal Blockchain の委任は不可逆です。委任時に指定した期間が最終確定値になります。

05経済 3% の手数料は他バリデータと比べて?

プロトコル下限 2%、稼働中のバリデータは 2〜10% に分布。当方は下限の 1 つ上(3%)を採用、運用コストを反映しつつ運用負荷に見合った価格設定としています。

06運用 委任中にバリデータの期間が終了したら?

プロトコルはバリデータの残期間を超える委任を受け付けません。委任可能なのはバリデータの残期間まで。当方は期間切れ前に必ず再登録するため、実質的なリスクではありません。

07信頼 コードは公開されていますか?

はい。本サイト、監視スクリプト、災害復旧手順、バリデータ更新 runbook はすべて public Git リポジトリで管理しており、運用の中身を全部閲覧・監査できます。

  • あらゆるバリデータを選ぶ delegator 当方以外を選ぶ方も含めて。ステーキングが多数のバリデータに分散される方が、少数に集中するよりネットワーク全体の健全性が高くなります。
  • Avalanche エコシステム全体 Metal Blockchain は Avalanche の consensus 革新・ツール・セキュリティ研究を継承しています。当方が直接支払っていない研究成果の恩恵を受けています。
