Cycle 単位 audit packet(準備中)

準備中

/api/cycle-history.jsonl として JSONL フィードを準備中です。各行が 1 つのクローズ済 cycle で、 /api/uptime-cycles.json と /api/incidents.json を join し、 読者が line-by-line で audit packet を stream 処理できる形式です。 スキーマは事前公開しており /api/cycle-history.example.jsonl で参照可能。生成スクリプトは公開リポジトリ内 scripts/gen-cycle-history.sh。

アイデンティティ署名(進行中)

進行中

署名付きアイデンティティマニフェストを準備中です。validator の staker.key および BLS signer.key とは独立した運用者専用 identity key(ed25519)を使用します。検証には namespace freedom-yield/validator-identity の OpenSSH signature を使います。この過程で validator の signing key は使用しません。スキーマは事前公開しており /api/identity.example.json で参照できます。検証手順は docs/IDENTITY_VERIFICATION.md に記載しています。
