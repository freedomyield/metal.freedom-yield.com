アイデンティティ検証

Freedom Yield は、 暗号署名された運用者アイデンティティマニフェストと Merkle DAG の監査パケットを公開しています。 独立した検証者は curl / jq / ssh-keygen -Y verify だけで、 公開アーティファクトから全 claim を再現可能 — プロジェクト固有のツールは不要です。 本ページは、 その監査のための単一エントリーポイントです。

  1. ホーム
  2. 公開データ
  3. アイデンティティ検証

クイックスタート (60 秒)

ライブのアイデンティティマニフェストが、 公開された運用者公開鍵で署名されていることを確認します:

TMP=$(mktemp -d)
curl -sS https://metal.freedom-yield.com/.well-known/operator-identity.pub > "$TMP/pub"
curl -sS https://metal.freedom-yield.com/api/identity.json                 > "$TMP/json"
curl -sS https://metal.freedom-yield.com/api/identity.json.sig             > "$TMP/sig"
printf 'freedom-yield %s\n' "$(cat "$TMP/pub")" > "$TMP/allowed"
ssh-keygen -Y verify -f "$TMP/allowed" \
  -I freedom-yield \
  -n freedom-yield/validator-identity \
  -s "$TMP/sig" < "$TMP/json"
# 期待値: Good "freedom-yield/validator-identity" signature for freedom-yield with ED25519 key SHA256:rQZNC53Jdp…

OpenSSH 8.0+ 必須 (ssh-keygen -Y サブコマンドは 2019-04 から)。 macOS 11+ / モダン Linux / Windows OpenSSH 8.0+ で動作。
