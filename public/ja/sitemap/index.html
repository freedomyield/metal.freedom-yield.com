機関向け (For institutions)

デューデリジェンス・評価用 hub。 各 page は operator の commitment / リスク / 管轄 / アーキテクチャ surface における検証可能 artifact。

  • 選定エビデンスcluster index (14 evidence トピック)。
  • 運用者の commitment10 個の一方的 commitment + 根拠 + 限界明示。
  • リスク開示運用者が minimise しない既知リスク。
  • 管轄姿勢運用者の管轄とタイムゾーンカバー。
  • セキュリティ姿勢多層防御 + 情報分類。
  • 事業継続性validator / 運用者 / network / web 各障害シナリオ。
  • Transparent Validator Pledge署名付き pledge と cross-reference。
  • Subnet 適性8 軸の直視的スコアカード。
  • リファレンスアーキテクチャ2 ホストトポロジ、 3 鍵分離。
  • Subnet pilot 意思表明pull-only な expression of interest。
  • 廃止予告ポリシー事前予告 lead time と引継 commitment。
  • 問い合わせ日本の営業日 24 時間以内の初回応答 target。

委任者向け (For delegators)

委任側 material: 委任手順、 stake が守られる仕組み、 障害時に運用者がどう動くか。

  • 委任ライブ capacity、 fee、 6 ステップの委任 flow。
  • ライブ状態現 cycle、 ネットワーク uptime、 capacity (Home と同じデータ)。
  • 事業継続性機関向けからの cross-list — 各障害シナリオで stake がどう守られるか。

技術者向け (For engineers)

機械可読 surface と運用 artifact。 評価者が curl / jq / その他 HTTP-aware tool で消費可能。

  • 公開データカタログ全公開 JSON / JSONL endpoint と format / 更新頻度。
  • アイデンティティ検証運用者 identity manifest 検証手順(9 ステップ)。
  • 運用日誌cycle 毎の uptime、 tx ID、 explorer link。
  • ネットワーク観測fee / stake 分布、 ポジション context。
  • インシデントログSEV 分類済 incident と source JSON。
