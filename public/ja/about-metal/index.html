背景

About Metal Blockchain

Metal Blockchain は Metallicus 製の Layer-0 チェーン(XPR Network = Layer-1 と同じ親会社)。 Avalanche fork で、コンセンサスは Snowman。permissionless validator で、最小 stake を満たせば 誰でもバリデータになれます。

XPR Network との違い

XPR Network
Layer-1、Block Producer の consortium 制、既存 BP の multisig 承認が必要
Metal Blockchain
Layer-0、permissionless、stake ベース。Foundation 議席は最大 5 名の選出制

両チェーンは Metallicus が運営し、相互接続もされています。

バリデーションの仕組み

1. 誰でも参加可能(2,000 METAL から)

プロトコル最小 self stake は 2,000 METAL。XPR と違い既存 validator からの承認は不要です。 staking key をローカルで生成、"Add Validator" tx を P-Chain に送信、start time 到達で active 入り。

2. 報酬は uptime ドリブン、性能競争ではない

Snowman は PoW のような速度競争ではありません。ピアから到達でき、正しく投票していれば、 公式最小(8 vCPU / 16 GiB)を超えるハードを使っても報酬は増えません。 性能で殴っても収益は伸びないのがこのチェーンの特性です。

3. 自己 stake が受入枠を決める

最大 stake weight は min(3M METAL, 5 × self_stake)。自己 stake 2,000 → 最大 weight 10,000 (うち委任受入可能枠は 8,000)。この上限は「運用者の skin in the game と受入可能な委任量を整合させる」 ためのプロトコル仕様であり、成長目標ではありません。

4. スラッシングなし

Avalanche family にはスラッシング(stake 没収)がありません。ダウンタイム時の最悪は「報酬ゼロ」。 自己 stake も委任 stake も end time に必ず返却される(uptime に関係なく)。 delegator のリスクは「機会費用(逸失利益)」のみ、元本毀損ではありません。
