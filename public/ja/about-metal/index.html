背景

About Metal Blockchain

Metal Blockchain は Metallicus 製の Layer-0 チェーン(XPR Network = Layer-1 と同じ親会社)。 Avalanche fork で、コンセンサスは Snowman。permissionless validator で、最小 stake を満たせば 誰でもバリデータになれます。

XPR Network との違い

XPR Network
Layer-1、Block Producer の consortium 制、既存 BP の multisig 承認が必要
Metal Blockchain
Layer-0、permissionless、stake ベース。Foundation 議席は最大 5 名の選出制

両チェーンは Metallicus が運営し、相互接続もされています。

バリデーションの仕組み

  • 1. 誰でも参加可能(2,000 METAL から)

    プロトコル最小 self stake は 2,000 METAL。XPR と違い既存 validator からの承認は不要。staking key をローカル生成 → Add Validator tx を P-Chain に送信 → start time 到達で active 入り。

  • 2. 報酬は uptime ドリブン

    Snowman は速度競争ではない。ピアから到達でき正しく投票していれば、公式最小(8 vCPU / 16 GiB)を超えるハードでも報酬は増えない。性能で殴っても収益は伸びないのがこのチェーンの特性。

  • 3. 自己 stake が受入枠を決める

    最大 stake weight = min(3M METAL, 5 × self_stake)。自己 stake 2,000 → 最大 weight 10,000(うち委任受入可能 8,000)。「skin in the game と受入量を整合」させるプロトコル仕様。

  • 4. スラッシングなし

    Avalanche family にはスラッシング(stake 没収)がない。ダウンタイム時の最悪は「報酬ゼロ」。自己 stake も委任 stake も end time に必ず返却(uptime 関係なく)。delegator のリスクは「機会費用」のみ。

今後の展望

ロードマップ

validator は終わりのあるプロジェクトではなく、長期間の規律です。約束していること、今後の判断軸を明示します。

  1. 2026-05 → 2027-05 進行中

    Phase 1 — 積み増し

    12 か月 × 月次 cycle で運用。各 cycle で tx 投入 → ~30 日間稼働 → 再登録。外部資金の段階的 deploy で self-stake を ~3,000 METAL ずつ積み増し、cycle ごとに監査トレース(uptime ledger / incidents / cadence)を公開。委任獲得は積極追求せず、来れば lucky。1 年後に確実に残るもの: 12 cycle 完走実績と公開された監査トレース。

  2. 2027-05 判断点

    Phase 2 review

    12 cycle 完走 + 12 か月の監査トレース蓄積。この時点で再判断: cycle 期間を延ばすか? 委任獲得を本格化するか? 判断は今 roadmap に書いた線ではなく、1 年間蓄積した事実ベースで行います。

  3. 期限なし Long-term

    Beyond Phase 2

    Metal Blockchain ecosystem の進化に合わせて継続的に貢献。validator 運営に終わりはなく、約束できるのは operational quality の継続だけ。
