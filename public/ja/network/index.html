手数料分布

active validator が delegation fee の各帯にどう分布しているかを、 /api/peers.json の各 validator の delegation_fee_pct から導いた集計です。2.0% 帯はプロトコル最低値 (チェーンが許容する最小)で、他の帯は運用者が設定した値を観測しやすい区切りでグルーピング したものです。

Self-stake 分布

active validator が self-stake の各帯にどう分布しているかを、 /api/peers.json の各 validator の self_stake_metal から導いた集計です。最下帯の下限 2k METAL は、 プロトコル上 validator として登録するために必要な self-stake の最小値です。

出典と限界

  • データ出典: 本ノードの validator host 上の local metalgo を platform.getCurrentValidators で問い合わせ、scripts/peer-validators.sh が /api/peers.json として書き出しています。
  • 更新頻度: 1 日 1 回。
  • 古さ: 観測値は最大 24 時間前のものになり得ます。各セクションは観測時刻をインラインで表示しています。
  • 公開していない情報: IP アドレス、geo-IP 属性、運用者の個人情報は含めません。on-chain で確認できる識別子(NodeID)と on-chain 数値フィールド(stake / fee / uptime%)のみを掲載します。
  • 追加の分析 feed は今後接続予定 — 以下のエンドポイントはパイプライン上は存在しますが、現時点では public 配信していません:
    • /api/peers-gini.json — 未配信(後日接続予定)
    • /api/fee-market.json — 未配信(後日接続予定)
    • /api/peers-changes.json — 未配信(後日接続予定)
  • 比較や評価は含めない: 上記バケットは単純な数値軸上のどこに validator が位置しているかを示すものです。特定運用者の品質評価ではなく、そのように読まれるべきでもありません。
