この記録について

このページは long-horizon の台帳です。各 entry は Metal Blockchain P-Chain 上の AddPermissionlessValidatorTx 1 cycle に対応します。 一度書いた entry は後から編集しません — 誤りが発見されたら次の cycle の note で訂正を追記し、元の entry は immutable record として残します。

運用者ノートは意図的に短く書きます: 何が起きたか / 何を学んだか / 次 cycle で何を変えるか。 marketing channel ではなく、tx ID だけでは伝わらない監査トレースの一部です。
