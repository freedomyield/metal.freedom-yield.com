# Current crawl policy: open to AI agents that read on a person's request and
# to AI search crawlers; closed to training crawlers, general search engines
# and everyone else.
#
# This site is published for institutional readers who arrive at a specific
# URL. Indexing is still suppressed at two other layers (this file is the
# only layer that changed):
#   1. <meta name="robots" content="noindex, nofollow"> on every HTML page
#   2. X-Robots-Tag: noindex, nofollow, noarchive, nosnippet on every response
# Both stay on because the AI vendors do not document, in their official bot
# pages, a per-bot way to lift noindex. The third layer is this file, which
# now has per-bot groups below.
#
# The explicit per-bot lines exist because Cloudflare may inject an
# "Allow: /" against User-agent: * higher up in the file. Under RFC 9309 a
# matching specific group is used instead of the wildcard group, so the
# per-bot entries make our intent unambiguous regardless of any CDN
# managed-content injection.
#
# User-initiated fetchers (ChatGPT-User, Perplexity-User) are documented by
# their operators as possibly not following robots.txt.
#
# If the operator decides to open the site further (e.g., to search engines),
# the steps are: edit this file, the X-Robots-Tag in caddy/Caddyfile, and each
# page's meta robots tag.
