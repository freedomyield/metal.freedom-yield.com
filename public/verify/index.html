Engineer entry point

Identity verification

Freedom Yield publishes a cryptographically signed operator identity manifest and a Merkle-DAG audit packet. An independent verifier can reproduce every claim from public artifacts with curl, jq, and ssh-keygen -Y verify — no project-specific tooling required. This page is the single entry point for that audit.

Quick start (60 seconds)

Confirms that the live identity manifest is signed by the operator's published public key:

TMP=$(mktemp -d)
curl -sS https://metal.freedom-yield.com/.well-known/operator-identity.pub > "$TMP/pub"
curl -sS https://metal.freedom-yield.com/api/identity.json                 > "$TMP/json"
curl -sS https://metal.freedom-yield.com/api/identity.json.sig             > "$TMP/sig"
printf 'freedom-yield %s\n' "$(cat "$TMP/pub")" > "$TMP/allowed"
ssh-keygen -Y verify -f "$TMP/allowed" \
  -I freedom-yield \
  -n freedom-yield/validator-identity \
  -s "$TMP/sig" < "$TMP/json"
# Expect: Good "freedom-yield/validator-identity" signature for freedom-yield with ED25519 key SHA256:rQZNC53Jdp…

Requires OpenSSH 8.0+ (ssh-keygen -Y was added in 2019-04). macOS 11+, modern Linux, and Windows OpenSSH 8.0+ are all supported.

Live artifacts

All five Phase α artifacts are live and served from this domain. Each is independently fetchable; together they form a self-describing audit packet.

Signed identity manifest

live

Operator identity, fingerprint, bound artifact set, and the Merkle-DAG root hash. Signed with an ed25519 OpenSSH key whose public form is at /.well-known/operator-identity.pub.

Manifest
/api/identity.json
Signature
/api/identity.json.sig
Public key
/.well-known/operator-identity.pub
Schema
/api/identity.schema.v1.json + example

Merkle-DAG snapshot

live

A two-branch DAG of (i) operator identity-key history and (ii) closed validation cycles. The two branch roots combine into the dag_root_hash that the identity manifest also carries — they must match byte-for-byte.

Snapshot
/api/cycles-history.json
Identity-history leaf log
/api/identity-history.jsonl
Schema
/api/cycles-history.schema.v1.json

Cycle audit packet

live (1 cycle closed)

Append-only JSONL feed. One line per closed validation cycle, joining uptime + incidents + stake numbers for that cycle. Each leaf line's sha256 is folded into the cycles_branch of the Merkle DAG.

Feed
/api/cycle-history.jsonl
Schema
/api/cycle-history.schema.v1.json

On-chain anchor receipt

scheduled

At each cycle transition, the operator inscribes the current dag_root_hash on Metal A-chain (PulseVM / XPRNetwork) using a narrow metalfreedom@anchor permission, with memo fyid1:<dag_root_hash>. The receipt JSON is the audit-side index of those inscriptions.

Receipt
/api/anchor-receipt.json (= first broadcast scheduled for cycle 3 start, 2026-07-04 13:00 JST)
Schema
/api/anchor-receipt.schema.v1.json
