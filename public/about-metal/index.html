Background

About Metal Blockchain

Metal Blockchain is a Layer-0 chain by Metallicus, the same parent company behind XPR Network (Layer-1). It is an Avalanche fork using Snowman consensus, with a permissionless validator set — anyone with the minimum stake can become a validator.

How it differs from XPR Network

XPR Network
Layer-1, consortium of Block Producers, approval by multisig of existing BPs
Metal Blockchain
Layer-0, permissionless, stake-based; Foundation council has up to 5 elected members

Both chains are operated by Metallicus and are cross-chain connected.

How validation works

1. Anyone can validate (with 2,000 METAL)

The protocol minimum self-stake is 2,000 METAL. There is no need to obtain prior approval from existing validators (unlike XPR's consortium model). A staking key is generated locally, an "Add Validator" transaction is sent to the P-Chain, and after the start time the node enters the active set.

2. Rewards are uptime-driven, not throughput-driven

Snowman consensus is not a speed race like PoW. As long as the node is reachable by enough peers and votes correctly, the rewards are the same regardless of hardware muscle above the official minimum (8 vCPU / 16 GiB). Faster hardware does not earn more.

3. Self-stake determines delegation capacity

Maximum stake weight is min(3M METAL, 5 × self_stake). So 2,000 self-stake → max 10,000 weight (of which 8,000 can be received as delegations). The cap exists to align operator skin-in-the-game with how much delegation they can accept; it is a protocol property, not a growth target.

4. No slashing

Avalanche family chains have no slashing. The worst case for downtime is "no rewards for the staking period." Both self-stake and delegated stake are returned at end time, regardless of uptime. The risk delegators take is opportunity cost (missed yield), not loss of principal.

What's next

Roadmap

A validator is a long-horizon discipline, not a project with a finish line. Here's what we've committed to, and how we decide what comes next.

  1. 2026-05 → 2027-05 In progress

    Phase 1 — Accumulation

    Twelve monthly cycles. Each cycle: file the tx, run for ~30 days, renew. Self-stake grows incrementally as external capital is deployed (~3,000 METAL per cycle). Audit traces — uptime ledger, incidents, cadence — are published every cycle. Delegations are not actively pursued; the focus is operational discipline and record-keeping. Whether or not delegations arrive, the year produces what matters most: twelve cycle completions and a public track record.

  2. 2027-05 Decision point

    Phase 2 review

    Twelve cycle completions, twelve months of audit trace. At this point we reassess: extend cycle duration? Begin to actively accept delegations? The judgment is made from a year of evidence, not from a line drawn today.

  3. Open-ended Long-term

    Beyond Phase 2

    Continue contributing within the Metal Blockchain ecosystem as it evolves. Validator operation has no fixed finish line; the only durable commitment is to operational quality and to staying useful as the network changes around it.
