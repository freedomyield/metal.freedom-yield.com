Identity binding (in preparation)

in preparation

A signed identity manifest is being prepared. It uses a dedicated operator identity key (ed25519), independent of the validator's staker.key and BLS signer.key. Verification uses OpenSSH signatures with namespace freedom-yield/validator-identity. The validator's signing keys will not be used for this process.

Operator identity evidence is being revised to use an operator-signed artifact snapshot. The previously planned P-Chain memo binding will not be used.

The formal schema is live at /api/identity.schema.v1.json; a worked example is at /api/identity.example.json. Verifier and operator documentation are being updated in step with the model revision.

Status
In preparation — schema and operator-side generator are published; runtime identity.json remains gated on internal operational checks. The former P-Chain memo design has been retired.
