Source & limitations

  • Data source: local metalgo on this node's validator host, queried via platform.getCurrentValidators by scripts/peer-validators.sh; written out as /api/peers.json.
  • Refresh cadence: daily.
  • Staleness: the observation can be up to ~24 hours old. Each section labels its observation time inline.
  • What's not exposed: no IP addresses, no geo-IP attribution, no operator personal data. Only on-chain identifiers (NodeID) and on-chain numeric fields (stake, fee, uptime%) appear here.
  • Additional analytic feeds are still being wired — these endpoints exist in the data pipeline but are not yet publicly served:
    • /api/peers-gini.json — not yet available
    • /api/fee-market.json — not yet available
    • /api/peers-changes.json — not yet available
  • No comparison or assessment: the buckets above describe where validators sit on simple numeric axes. They are not a quality assessment of any operator and should not be read as such.
